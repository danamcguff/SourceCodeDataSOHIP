# SOHIP Bending Angle Dataset

This directory contains the released dataset:

`sohip_measurements.nc`

## Release Information

- Dataset title: SOHIP measurements
- LLNL dataset identifier: LLNL-DATA-2024973
- Control/publication number: CP 2026-323
- Distribution type: Unlimited/ CC BY 4.0 
- Authors: Shuang Xu, Lance M. Simms, Cesar Laguna, Philip Cameron-Smith, Walter Hannah, and Dana L. McGuffin

## File Description

Comprehensive dataset containing bending angle measurements, star intensity, and retrieved atmospheric profiles (refractivity and density) from SOHIP stellar occultation observations aboard the International Space Station.

The instrument collected several million images of stars, and the data included here is from processing those images to extract star intensity and its motion as "refractive bending angle" and then further processing those measurements to retrieve atmospheric refractive index and density. The other variables in the dataset are other metadata related to timing, geolocation of the line-of-sight from telescope on ISS to star imaged, and status information about each observation.
